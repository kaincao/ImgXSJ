Codex 需要验证手机号，我们该怎么办？

之前我给一个朋友装了 Codex 桌面版，结果卡在了手机号验证这里。

这个验证还是必选项，但大陆手机号收不到验证码，他手上又没有能用的国际手机号，所以 Codex 虽然装好了，最后一直没用上。

昨天我看到一个插件，可以直接使用你网页版 ChatGPT 已经登录好的账号信息，亲测有效，所以分享一下。

这个方法的原理是：

你的 Chrome 浏览器里面，ChatGPT 是可以使用邮箱登录的。

插件做的事情，就是把你浏览器里这份“已经登录成功的身份信息”导出来，生成一个 auth.json 文件，然后再把这个文件放进 Codex 的指定文件夹。

Codex 看到这份文件以后，就知道：哦，这个账号已经登录过了，于是可以直接读取这份登录状态。

插件是这个：

codex-auth-helper（Codex 认证助手）

仓库：

https://github.com/zhishile/codex-auth-helper

────────────────────────

1/ 先把插件下载下来

打开上面的 GitHub 地址，进去以后，找到绿色的 Code

点开以后选择 Download ZIP，下载后解压。

这里注意不要直接选最外层的文件夹。

打开解压出来的文件夹以后，里面还有一个：extension

我们需要的是这个文件夹。

如何判断自己有没有选对：

打开 extension 以后，你应该能看到类似：

manifest.json、icons、popup 等这些文件。

看到 manifest.json 基本就说明找对了。

────────────────────────

2/ 把插件装进 Chrome

打开 Chrome，直接在地址栏输入 ：

chrome://extensions/

然后回车。

进去以后：

① 打开右上角的 「开发者模式」

② 点击左上角 「加载已解压的扩展程序」

③ 选择刚才找到的 extension 文件夹

加载成功以后，你的 Chrome 里面就会多出一个：

Codex 认证助手

建议顺手点一下 Chrome 右上角的拼图图标，把它固定到浏览器工具栏。

────────────────────────

3/ 把自己的登录信息导出来

接下来先打开：http://chatgpt.com

确认你的 ChatGPT 已经正常登录。

然后点击浏览器右上角刚才安装好的 Codex 认证助手。

如果插件能够正常识别你的账号，你会看到自己的账号、套餐以及登录凭证剩余有效时间等信息。

然后点击里面生成 / 保存 auth.json 的按钮。

浏览器会下载一个文件：auth.json

这个文件非常重要。

你可以把它理解成 Codex 用来识别你登录身份的文件。

所以不要把这个文件发给别人，也不要上传到网盘、群聊或者任何公开的地方。

────────────────────────

4/ 把 auth.json 放进 Codex 文件夹

这一步很多不熟悉电脑的人可能会懵，所以我详细说一下。

Windows 用户按：Win + R

然后输入：%USERPROFILE%\.codex\   回车。

把刚才下载的：auth.json  直接放进这个文件夹。

最后应该是：%USERPROFILE%\.codex\auth.json

如果里面本来已经有一个 auth.json，就用新下载的覆盖掉。

Mac 用户

打开 Finder，顶部菜单选择：

前往 → 前往文件夹

或者直接按：Command + Shift + G

输入：~/.codex/  回车。

然后把刚才下载的：auth.json  放进去。

最后的位置就是：~/.codex/auth.json

如果原来已经有一个，就直接覆盖。

────────────────────────

5/ 重新打开 Codex

文件放好以后，彻底退出 Codex 桌面端。（要确保 Codex 已经完全退出，后台也没有继续运行。）

然后重新打开 Codex。

如果前面的步骤都正确，Codex 就会读取刚才放进去的 auth.json。

最后还有一点：

这个 auth.json 不是永久有效的，插件里面会显示剩余有效时间。

如果失效了，重新打开已经登录 ChatGPT 的 Chrome：

点插件 → 再生成一次 auth.json → 覆盖掉原来的文件。

然后重启 Codex 就会重新生效。
